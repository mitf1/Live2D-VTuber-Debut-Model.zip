# Live2D 皮套制作项目包

一套面向 **2D 虚拟主播（Live2D）皮套定制** 的完整需求资料，包含拆件规格、参数设计、补画清单与验收标准。

角色设定：兔子耳少女 — 白发 + 金色发尾，米色围裙连衣裙，蓝色领带，藏青短裤，白袜，棕色乐福鞋，蓬松兔尾。
目标平台：**VTube Studio / PrprLive**，直播实时驱动，中远景半身运镜。

---

## 这是什么

很多人在定制 Live2D 皮套时踩同一个坑：**只拿到一张扁平立绘，以为可以直接用**。实际上从"一张画"到"能动的皮套"，中间隔着三件事：

1. **拆件**（把画切成 95~150 个可动图层）
2. **补画**（画出原画里被遮住、根本不存在的那部分）
3. **绑定**（用 Cubism 加参数、物理、表情）

这个仓库把三件事的规格全部写死了，目的是：

- 你拿它去询价，画师/建模师能直接看懂要做什么，报价不再靠猜
- 你知道该验收什么，不会等到成品交付才发现"耳朵不会动"
- 争议点（尤其是补画）提前写进文档，避免后期加价

## 快速开始

### 如果你是要定制皮套的主播

1. 打开 `拆件分区图.png` 和 `必须补画区域图.png`，先建立"工作量在哪"的概念
2. 把 `询价话术.txt` 全文复制给候选建模师
3. 收到报价后，用 `分层清单.csv` 对照层数 —— 对方只报 60 层就要问清楚：兔耳、金发尾、裙摆分片是不是被合并了
4. 签约时把 `需求书.md` 第八节「验收标准」整段附进合同
5. 交付时逐条打卡验收

### 如果你是要接单的画师 / 建模师

1. `角色立绘.png` 是起点，需要补画分层 PSD（规格见需求书第二节、第三节）
2. `必须补画区域图.png` 里 10 处是**必须**补的，不做必穿模
3. `Live2D参数绑定表.csv` 已给出每个参数的极限值表现，照表配即可
4. 交付必须含 `.cmo3` 工程 + 分层 PSD，不接受只给 `.moc3` 成品包

## 核心规格速览

| 项目 | 规格 |
|---|---|
| 目标运行时 | Live2D Cubism 4/5 → `.moc3` + `.model3.json` 文件夹 |
| 画布 | 4000 × 4000 px，RGB / 8bit，透明底 |
| 部件外扩 | 8~15 px（防脱模露边） |
| 层数 | 建议 95~150 层，低于 90 层手感明显发僵 |
| 必补画区域 | 10 处 |
| 参数 | 17 个标准 + 17 个专属（含兔耳、呆毛、兔尾、领带、裙摆） |
| 物理 | 5 组：前发/鬓发、后发+金发尾、兔耳、兔尾、领带+裙摆+缎带 |
| 表情 | ≥ 8 个 `exp3.json` |
| 动作 | Idle（无缝循环）+ 挥手 + 打招呼 + 惊讶 |
| 帧率 | 60 fps 稳定，模型包建议 < 40 MB |

**角色专属卖点参数**（没有这些，皮套就只会呼吸和眨眼）：

```
ParamEarL / ParamEarR     兔耳左右摆（两侧相位错开）
ParamEarBendL / R         兔耳前倾竖起（惊讶、开心）
ParamAhoge                呆毛抖动
ParamTail                 兔尾摆动
ParamTie                  领带摆动
ParamSkirt                裙摆飘动
ParamHairBack             后发 + 金发尾滞后跟随
```

## 最容易翻车的 5 个点

1. **只给一张扁平 PNG** — 无法直接变皮套，必须补画 + 分层。这是全部工作量的 60%
2. **补画没写进报价** — 腋下、肩关节、裙内侧、嘴内这些"看不见的地方"不算钱，后期一定扯皮
3. **只交付 `.moc3`** — 想加个表情就得整套重做，务必索要 `.cmo3` 工程
4. **没做面捕映射** — 只能手动点表情，等于半个废模型
5. **层数虚报** — 报 130 层实际 70 层，动起来头发会一块一块跳

| 档次 | 层数 | 参考报价 | 绑定工期 |
|---|---|---|---|
| 基础半身 | 60~80 | 2,000~4,000 元 | 5~8 工作日 |
| 标准全身 | 100~130 | 5,000~10,000 元 | 7~15 工作日 |

> 市场价波动大，仅作判断量级用。头部建模师通常需要提前 1~3 个月约档期。

## 修改建议

这套文档是模板化的，换角色时只需改动：

- `角色立绘.png` — 换成新的立绘
- 需求书第三节「拆件清单」— 按新角色增减部件
- 需求书第四节 4.2「自定义参数」— 换成新角色的特征（兽耳？裙摆？披风？）
- 两张标注图 — 需要重新标坐标

标准参数部分、验收清单、面捕要求是通用的，可以原样复用。
